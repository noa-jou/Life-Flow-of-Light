# 歲月流明

[Life Flow of Light](README.md)

**以燈光活動輔助觀察獨居生活的隱私友善概念驗證專案**

## 一、專案簡介

**「歲月流明」（Life Flow of Light）** 是一個概念驗證（Proof of Concept，PoC）專案，旨在探索能否透過記錄日常生活中的電燈開關狀態，以被動、低干擾及相對尊重隱私的方式，觀察獨居人士，尤其是獨居長者，在家中是否仍有活動的跡象。

本構想希望讓家屬不必依賴攝影機、麥克風等較具侵入性的監控設備，也能透過有限的生活活動紀錄，留意親人的日常作息是否出現異常變化。

然而，要將這個構想真正轉化為可靠且具商業規模的服務，仍需要具備硬體研發、智慧家庭整合、雲端服務、資訊安全及營運能力的企業投入資源。

**因此，本專案僅是一份產品概念提案，而非完整的商業化產品。**

我製作這個專案，主要是希望透過具體的程式作品，展示自己的創意、軟體開發能力，以及從生活問題出發進行產品設計的思考方式，作為個人求職作品集的一部分。

同時，我也歡迎對此構想有興趣的企業、研究人員或開發者聯絡討論。

若有企業希望將本專案的原創程式碼或其他受著作權保護的內容用於商業用途，請先與我聯絡，討論授權並取得許可。

## 二、靈感來源與產品構想

「歲月流明」這個名稱，來自中文裡將光線比喻為生命與時間的說法：

- **「人死如燈滅」**：以燈火的熄滅，比喻生命的終結。
- **「一寸光陰一寸金」**：以光陰形容時間，提醒人們珍惜生命中的每一刻。

這些說法讓我想到：光線不只是照亮生活的工具，也可能成為觀察生活活動的一種溫和線索。

即使是一位很少使用手機、電腦或其他電子設備的長者，在日常生活中，往往仍然會有開燈、關燈的習慣。

例如，清晨打開臥室的燈、傍晚開啟客廳的燈，或是在就寢前關掉家中的照明設備。

單獨看待這些行為，它們並沒有什麼特殊意義；但如果將燈光狀態與時間持續記錄下來，或許就能觀察到某些日常生活模式。

對於不願意在家中安裝攝影機的長者而言，在本人知情且同意的前提下，讓可信任的家屬查閱有限的燈光活動紀錄，可能是一種相對容易接受的替代方案。

事實上，智慧燈泡、智慧開關及相關物聯網技術早已存在。許多設備已經能夠回報自身的開關狀態，並依照所在位置標示為「客廳」、「臥室」等不同空間。

我的提議並不是重新發明智慧燈泡，而是探索如何將這些既有技術整合成一套專門服務獨居生活需求的雲端活動紀錄與視覺化系統。

系統不需要知道長者正在做什麼，而是嘗試從**日常環境狀態的變化**中，提供值得關注的生活線索。

在適當的資訊安全、使用者同意與存取權限管理下，家屬可以了解長期的活動模式，並在發現明顯變化時，主動聯絡或關心親人。

當然，燈光活動並不等於人的活動。長時間沒有開關燈，不一定表示發生危險；即使燈光正常變化，也不能保證長者安全。

因此，本構想應被視為輔助觀察工具，而非獨立的緊急救援或安全保障系統。

## 三、概念驗證與技術範圍

本專案預計開發一個簡單的前端介面與輕量化後端，以視覺化方式展示整套系統可能如何運作。

預計包含以下功能：

- **虛擬智慧燈具：** 透過網頁模擬不同房間的燈光開關。
- **事件紀錄：** 將燈光開啟及關閉的時間寫入資料庫。
- **活動時間軸：** 以類似甘特圖的方式，呈現各房間的燈光活動。
- **基本資料流程：** 展示燈光事件如何被產生、儲存，再呈現給獲授權的使用者。

在這個初步 PoC 中，燈光事件將由使用者直接操作前端介面產生，而不是來自真實的智慧燈泡或實體感測器。

**本階段不打算進行硬體開發或整合。**

這個專案的目的，是讓讀者可以直觀理解產品構想，而非自行完成整套智慧家庭系統。

若未來要真正投入商業應用，仍需要進一步研究硬體整合、雲端通訊、資料庫擴充、身份驗證、資訊安全、使用者同意機制，以及異常判斷與誤報等問題。

## 四、延伸構想：摩斯密碼通訊

除了觀察日常燈光活動，我也想到另一種可能的應用：

**透過特定的開關燈節奏，傳遞摩斯密碼（Morse Code）。**

例如，使用者可以透過一組事先約定的燈光開關節奏，傳遞簡短訊息或求助訊號。

這或許能讓不方便操作手機的人，透過家中原本就有的照明設備，以較不顯眼的方式進行簡單通訊。

不過，這仍屬於尚未驗證的延伸構想。實際應用時，還必須考慮誤觸、訊號辨識準確度、通訊可靠性、隱私及使用者同意等問題。
